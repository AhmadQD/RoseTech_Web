1. Sensing

The Taif rose is monitored with a DHT22 sensor for temperature and humidity, plus a capacitive soil moisture sensor. These readings tell the system whether the plant environment is healthy or starting to drift out of range.

2. Edge computing

An ESP32 node reads the sensor data, converts the soil signal into a percentage, and packages everything into a single JSON message. This keeps the data structured before it is transmitted wirelessly.

3. Relay and storage

The ESP32 gateway receives the message over ESP-NOW and forwards it to the backend over Wi-Fi. The backend validates the readings and stores them so they can be reviewed later or displayed in a dashboard.

Data contract

Every reading travels as one JSON message with these fields.

{
  node_id,
  seq,
  source,
  temperature_c,
  humidity_pct,
  soil_moisture_pct
}

What this project is

A monitoring and early-detection system for Taif roses. It only reads and reports: sensors and a camera observe, the backend stores and analyzes, the dashboard and a mobile app show. This page explains the idea and shows no live data.
